# JAVHDPorn Downloader

Official Windows installer releases for **JAVHDPorn Downloader**.

The application downloads individual public video pages that the user has the legal right to save, resolves the best available quality, and produces a playable MP4.

## Install

Download the latest `JAVHDPorn-Downloader-Setup-*.exe` file from the repository's **Releases** page and run it. The installer includes all required application runtime components.

## Features

- Self-contained Windows installation
- Best-quality video downloads
- Protected HLS fragment decoding and validation
- Light, Dark, and branded Icon themes
- Start Menu and optional desktop shortcuts
